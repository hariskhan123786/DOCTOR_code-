## 📖 Overview

CodeDoctor AI is a modern web application that simulates an AI-powered code review experience using intelligent rule-based analysis. Developers can paste source code into the editor, select or automatically detect the programming language, and receive a detailed report covering code quality, security, performance, maintainability, readability, and best practices.

The project is designed as a frontend-only application and runs entirely inside the browser without requiring any backend services or external AI APIs.
